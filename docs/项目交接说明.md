# 街巷消杀轨迹系统 V1 项目交接说明

## 项目定位

本项目用于在广州天地图上叠加查看多名消杀工作人员的 GPX 轨迹，让使用者直观看到工作人员实际经过的道路和街巷。它是人工判断的辅助工具，不是完整业务管理平台。

## V1 能力

- 多 GPX 导入、同图叠加、颜色区分、单轨显隐与定位。
- 广州天地图矢量/卫星切换。
- 原始轨迹与保守道路吸附轨迹切换。
- 可开关、可调米数的消杀覆盖辅助范围。
- SQLite 历史任务保存、日期分级、恢复与删除。

## 数据原则

原始 GPX 永久完整保留。原始 GeoJSON 与道路吸附 GeoJSON 分栏保存，任何派生处理不得覆盖原始数据。覆盖半径只用于视觉辅助，不代表实际完成消杀。

数据库默认为 `data/tracks.sqlite`，仅包含 `tasks` 和 `tracks` 两张业务表。每台电脑数据独立，数据库不进入 Git。

## 部署方式

V1 采用私人 GitHub、Windows 本地 Node 服务和 SQLite。新电脑只需安装 Git、Node.js LTS，然后执行：

```text
Clone → 首次安装.bat → 启动系统.bat
```

天地图部署配置随私人仓库提供。若未来公开发布，应先轮换并移除仓库中的 Key。

## 明确不包含

实时定位、手机采集、多人共享数据库、账号权限、人员档案、任务派发、自动漏消杀、AI 分析、自动报表、覆盖率统计和街巷管理均不属于 V1。

## 接手时优先检查

依次查看 README、`package.json`、两个 BAT 脚本、`server.js`、地图配置、GPX 解析与道路吸附模块、`data` 目录。修改功能时应定位相关模块后作最小修改。

## V1 封版检查

确认 `.gitignore` 排除数据库、真实 GPX、日志、依赖、构建和缓存；执行 `npm run build` 与 `npm run test:persistence`；确认全新目录安装和启动后再发布标签。
