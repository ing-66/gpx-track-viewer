# 街巷消杀轨迹系统 V1 项目交接说明

## 项目定位

本项目用于在广州天地图上叠加查看多名消杀工作人员的 GPX 轨迹，让使用者直观看到工作人员实际经过的道路和街巷。它是人工判断的辅助工具，不是完整业务管理平台。

## V1 能力

- 多 GPX 导入、同图叠加、颜色区分、单轨显隐与定位。
- 广州天地图矢量/卫星切换。
- 原始轨迹与保守道路吸附轨迹切换。
- 可开关、可调米数的消杀覆盖辅助范围。
- IndexedDB 历史任务保存、日期分级、恢复与删除。

## 数据原则

原始 GPX 永久完整保留。原始 GeoJSON 与道路吸附 GeoJSON 分栏保存，任何派生处理不得覆盖原始数据。覆盖半径只用于视觉辅助，不代表实际完成消杀。

任务和轨迹按 `tasks`、`tracks` 两个对象仓库存入当前浏览器的 IndexedDB。每台电脑、每个浏览器的数据相互独立，真实 GPX 不进入 Git。

## 部署方式

V1 发行物为 `release/街巷轨迹.html`，用户直接双击使用，不依赖 Node 服务。开发者构建时执行：

```text
npm ci → npm run build → 分发 release/街巷轨迹.html
```

天地图配置随项目提供。面向公众长期分发时应为正式版本单独申请并限制 Key。

## 明确不包含

实时定位、手机采集、多人共享数据库、账号权限、人员档案、任务派发、自动漏消杀、AI 分析、自动报表、覆盖率统计和街巷管理均不属于 V1。

## 接手时优先检查

依次查看 README、`package.json`、`src/task-api.js`、地图配置、GPX 解析与道路吸附模块。修改功能时应定位相关模块后作最小修改。

## V1 封版检查

确认 `.gitignore` 排除数据库、真实 GPX、日志、依赖、构建和缓存；执行 `npm run build` 与 `npm run test:persistence`；确认全新目录安装和启动后再发布标签。
