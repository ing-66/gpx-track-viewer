# 街巷消杀轨迹系统启动说明书

## 首次使用

电脑需提前安装 Git 和 Node.js LTS。从私人 GitHub 仓库 Clone 项目后：

1. 双击 `首次安装.bat`。
2. 等待“首次安装完成”提示。
3. 双击 `启动系统.bat`。

系统会自动启动，并在默认浏览器打开 `http://127.0.0.1:8787/`。

## 日常使用

以后只需双击 `启动系统.bat`，无需重复安装。历史任务保存在本机 `data/tracks.sqlite`；不同电脑数据互相独立。删除项目目录前，请先备份 `data` 目录。

关闭浏览器不会删除数据。如需完全退出，可关闭“街巷消杀轨迹系统”服务窗口。下次重新双击启动脚本即可。

系统使用广州天地图，支持矢量地图与卫星影像，地图配置已随私人项目提供。

## 常见错误

### 未检测到 Node.js

安装 Node.js LTS，关闭所有 CMD/PowerShell 窗口，然后重新双击 `首次安装.bat`。可运行 `node -v` 确认安装。

### npm ci 失败

检查网络后重新执行首次安装。仍失败时，在项目目录运行 `npm cache verify` 和 `npm ci`；不要自行修改依赖文件。

### GitHub Clone 失败

私人仓库需要当前 GitHub 账号具备权限。`Repository not found` 或 `Authentication failed` 通常不是项目代码故障。

### 浏览器没有自动打开

手动访问 `http://127.0.0.1:8787/`。如无法访问，检查启动窗口错误信息。

### 端口被占用

先关闭之前的项目服务窗口。仍提示 `EADDRINUSE` 时，运行 `netstat -ano | findstr :8787` 检查占用，不要随意修改端口。

### 地图空白

先确认网络正常。若界面与轨迹正常而只有底图缺失，重点检查天地图服务、Key 和地图资源请求。

### GPX 没有显示

确认扩展名为 `.gpx` 且文件包含轨迹点。可先用 `test-data` 内模拟数据验证。

### 道路吸附不合理

切换回“原始轨迹”。吸附结果属于派生数据，永远不会覆盖原始 GPX；原则是宁可不吸附，也不要吸附错路。

### SQLite 无法打开

先关闭全部项目实例。不要直接删除数据库；先复制 `data` 目录备份再排查。

### 换电脑后没有旧任务

这是正常设计。每台电脑使用独立 SQLite，GitHub 只同步代码，不同步历史任务、真实 GPX 或数据库。
