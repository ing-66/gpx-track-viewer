# 街巷消杀轨迹系统使用说明

## 打开系统

取得 `街巷轨迹.html` 后直接双击，在 Edge、Chrome 等现代浏览器中打开即可。无需安装、无需启动服务。

## 本地数据

GPX 文件仅在当前浏览器中解析。保存任务后，原始 GPX、原始/吸附轨迹、颜色和地图设置存入该浏览器的 IndexedDB。

请固定使用同一个 HTML 文件位置和同一个浏览器。移动文件、换浏览器、清理浏览器数据或重装系统后，原有历史任务可能无法继续访问。

## 联网要求

软件界面和本地历史任务无需后端。天地图底图和新轨迹的道路吸附仍需联网；断网时可以查看原始轨迹和已保存的吸附结果，但在线地图资源可能无法显示。

## 常见问题

- 地图空白：检查网络、天地图服务及 Key。
- GPX 不显示：确认文件为 GPX 1.1 且包含轨迹点。
- 吸附不合理：切回“原始轨迹”，原始 GPX 不会被覆盖。
- 历史任务消失：确认使用同一浏览器和同一路径的 HTML，并检查是否清除了浏览器数据。
