# 模拟测试轨迹

本目录中的 GPX 均为功能测试用模拟数据，不代表任何工作人员的真实行动记录。

- `模拟-主干道与居民区.gpx`：模拟沿主干道行走后进入居民区、绕楼栋通行。
- `模拟-背街小巷.gpx`：模拟穿过背街小巷，与第一条路线局部重复。
- `模拟-环形巡查.gpx`：模拟环形巡查路线。
- `模拟-广州城中村与背街小巷.gpx`：模拟广州居民区、城中村内部和背街小巷的折返穿行。
- `模拟-广州平行道路吸附.gpx`：在平行道路附近加入轻微 GPS 偏移，用于验证方向连续且置信度足够时吸附、歧义点保留原位。

前三份坐标位于杭州市区；广州场景文件位于石牌村一带。全部仅用于验证多文件导入、颜色区分、轨迹开关、地图定位与底图细节辨识。
