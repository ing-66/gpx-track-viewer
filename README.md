# 街巷消杀轨迹系统

一个无后端、无数据库服务器的纯前端 GPX 轨迹查看工具。

## 普通用户使用

下载 [`release/街巷轨迹.html`](release/街巷轨迹.html)，双击即可在浏览器中使用。无需安装 Git、Node.js，也无需运行服务。

- GPX 仅在浏览器本地读取，不上传服务器。
- 历史任务保存在当前浏览器的 IndexedDB 中。
- 同一 HTML 文件换到另一台电脑或另一个浏览器后，历史任务不会自动跟随。
- 清除浏览器网站数据可能删除历史任务。
- 天地图和道路吸附功能需要联网。

## 功能

- 多份 GPX 1.1 轨迹导入、叠加、颜色区分、显隐和定位。
- 广州天地图矢量地图与卫星影像。
- 原始轨迹与保守道路吸附轨迹切换。
- 可开关、可调半径的消杀范围辅助显示。
- IndexedDB 历史任务保存、按日期查看、恢复和删除。

原始 GPX 永远完整保留。道路吸附属于派生数据，覆盖范围只用于辅助观察，不用于自动判断消杀完成情况。

## 开发构建

开发者安装 Node.js 后运行：

```bash
npm ci
npm run dev
npm run build
```

`npm run build` 会同时生成常规 Vite 构建和可直接双击的 `release/街巷轨迹.html`。

当前封版标识：`1.0.0-rc.1`。
