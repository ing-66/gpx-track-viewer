# 街巷消杀轨迹系统

## Windows 使用方法

首次使用：

1. 安装 Git。
2. 安装 Node.js LTS。
3. Clone 本项目。
4. 双击 `首次安装.bat`。
5. 双击 `启动系统.bat`。

以后使用：直接双击 `启动系统.bat`。

系统会在默认浏览器打开 `http://127.0.0.1:8787/`。请勿直接双击 `index.html`。

## 功能

- 多份 GPX 1.1 轨迹导入、叠加、颜色区分、显隐和定位。
- 广州天地图矢量地图与卫星影像。
- 原始轨迹与保守道路吸附轨迹切换。
- 可开关、可调半径的消杀范围辅助显示。
- SQLite 历史任务保存、按日期查看、恢复和删除。

原始 GPX 永远完整保留。道路吸附属于派生数据，覆盖范围只用于辅助观察，不用于自动判断消杀完成情况。

## 本地数据

数据库默认位于 `data/tracks.sqlite`，仅包含 `tasks`、`tracks` 两张业务表。数据库、真实 GPX、日志、依赖和构建文件不会提交到 Git；每台电脑的数据互相独立。

道路吸附需要将轨迹坐标发送到配置的步行道路匹配服务。当前配置适合轻量测试；正式长期使用建议部署自有或正式授权服务。

## 常见问题

- 未检测到 Node.js：安装 Node.js LTS，关闭终端窗口后重新运行首次安装。
- `npm ci` 失败：检查网络，运行 `npm cache verify` 后重试；不要自行修改依赖文件。
- 私人仓库 Clone 失败：确认 GitHub 账号拥有仓库权限。
- 浏览器未打开：手动访问 `http://127.0.0.1:8787/`。
- 端口被占用：关闭旧项目服务；可运行 `netstat -ano | findstr :8787` 检查。
- 地图空白：检查网络、天地图服务和 Key。
- GPX 不显示：确认文件包含轨迹点，可用 `test-data` 中模拟文件验证。
- 吸附不合理：切回“原始轨迹”，原始数据不会被修改。
- SQLite 异常：先关闭所有项目实例并备份 `data`，不要直接删除数据库。
- 换电脑没有旧任务：这是每台电脑独立保存的正常设计。

完整说明见 [启动说明书](docs/启动说明书.md) 和 [项目交接说明](docs/项目交接说明.md)。
